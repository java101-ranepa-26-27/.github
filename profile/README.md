## Как сдавать работу

1. Открой страницу шаблона и нажми **Use this template** → **Create a new repository**.
2. **Owner** — организация `java101-ranepa-26-27`, а не твой личный аккаунт.
3. Работай в отдельной ветке (`task1`, `task-2`, `task-final` — по номеру работы).
4. Сдай результат через **Pull Request** в `main`. Кнопку **Merge** не нажимай.

## Важно

В коде можно применять **только те концепции, которые разобраны на паре**. Если в работе
используется то, чего на занятии не было, это считается признаком генерации кода
ИИ-ассистентом — и работа **не засчитывается**.
